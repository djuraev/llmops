# Security guidance (MoliyaBank, fictional)

## SMS codes and passwords

MoliyaBank staff never ask for SMS codes, CVV codes, full card numbers or app passwords. Anyone asking for them is a fraudster, even if the caller ID shows the bank's number. Never share these codes.

## Suspicious activity

If you see a payment you did not make, block the card in the app and call 1234.
